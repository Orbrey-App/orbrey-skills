Illustrative format only. No real Orbrey household or schedule is represented.

- Task type: {{routine or contribution}}
- Title: {{user-supplied title}}
- Assignee: {{member resolved with members_list}}
- First date: {{YYYY-MM-DD}}
- Repeat unit and interval: {{supported values}}
- Weekdays: {{0 through 6 when applicable}}
- Day part or due time: {{supported value, if requested}}
- End date: {{repeat_ends_at or none}}

No task is created until the user approves this complete proposal. RRule strings, count limits, and date exclusions are not supported fields.
