---
name: household-digest
description: Create a concise, read-only household digest from records the authorised Orbrey tools return, clearly separating observations from suggestions.
---

Use this workflow when the user asks for a household or weekly digest.

1. Confirm the date range when “this week” or “last week” is ambiguous. Use household-local dates and the single household authorised to the connection.
2. Read relevant information with the available tools: `calendar_list`, `tasks_list`, `recipes_list`, `grocery_list`, and, when accessible and useful, `meal_plan_week` or `pantry_list`.
3. Respect tool visibility, connection scopes, and Orbrey plan access. If a domain is unavailable, say it was not checked; do not describe missing data as empty.
4. Summarise only returned events, task statuses, saved recipes, grocery items, pantry stock, or meal plans. Do not invent trends, purchase dates, calendar coverage, ages, or effort scores.
5. Use concise headings such as **Wins**, **Watch**, and **Suggested next steps**. Omit empty sections instead of manufacturing findings.
6. Keep the digest read-only. Do not change records or claim to have saved a report file.

If the user asks for a gentle digest, keep observations essential and kind. Treat recommendations as options, not actions already taken.
